# Sinkhole – Download

Sinkhole ist ein kooperatives Taktikspiel für bis zu vier Spieler: Jeder führt einen eigenen Trupp,
gemeinsam versiegelt ihr Löcher, aus denen ein Insektenschwarm kriecht.

**Herunterladen:** rechts unter **Releases** die neueste Fassung öffnen und die Zip-Datei für dein System laden
(Windows oder Linux, jeweils knapp 1 GB).

## Windows in Kürze

1. Zip laden, Rechtsklick → **Alle extrahieren**.
2. Im entpackten Ordner **Spielen** doppelklicken.
   Windows warnt, weil das Spiel nicht von einer Firma kommt: **Weitere Informationen** → **Trotzdem ausführen**.
3. Unter **EINSTELLUNGEN** deinen Namen eintragen und einmal das **TUTORIAL** spielen.
4. Zum Mitspielen: **BEITRETEN**, die Adresse des Gastgebers eintragen, Port 7777 lassen, **VERBINDEN**.

Die ausführliche Anleitung liegt als **ANLEITUNG.txt** im Ordner.

## Gut zu wissen

- Alle in einer Runde brauchen dieselbe Fassung. Nach einem Update meldet das Spiel sonst „Beitritt abgelehnt“.
- Deinstallieren: den Ordner löschen.
- Hier liegen nur die fertigen Spielpakete; der Quellcode ist nicht öffentlich.
